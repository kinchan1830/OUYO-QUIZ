# 応用情報 用語クイズ

応用情報技術者試験の用語を、CSV / JSON ファイルから取り込んでクイズ形式で解くための Web アプリです。
スマホでの利用を前提にしたシングルページアプリで、サーバーは不要です（GitHub Pages などに置くだけで動きます）。

## できること

- **問題ファイルの取り込み**：CSV または JSON を選ぶだけ（複数ファイル同時も可）
- **重複の排除**：問題文が同じ問題は 1 問として扱います。同じファイルを何度取り込んでも増えません。
  全角・半角、空白、末尾の「？」などの違いは無視して判定します。答えや解説を直したファイルを取り込むと内容が更新され、回答履歴はそのまま引き継がれます。
- **クイズ**：4択（他の問題の答えから選択肢を自動作成）／暗記カード（答えを見て自己採点）
- **出題設定**：分野、対象（すべて・未回答・前回まちがえた・正答率80%未満）、出題順（苦手優先・ランダム・取り込んだ順）、問題数
- **問題ごとの回答履歴**：○×の履歴、正答率、最終回答日時を記録し、問題一覧で確認できます
- **成績**：分野別の正答率
- **バックアップ**：問題と履歴を JSON で書き出し／読み込み（機種変更や複数端末用）
- **ホーム画面に追加**すればアプリのように起動でき、オフラインでも使えます（PWA）

データは端末のブラウザ（localStorage）に保存されます。

## 取り込めるファイル形式

`samples/` に例があります。

### CSV（UTF-8、BOM あり・なしどちらも可）

```csv
"id","分野","問題","答え","解説","出典"
"1","情報セキュリティ","ハッシュ値から元のデータを割り出すことが難しい性質を何というか","一方向性","…","R6秋 問1 設問1"
```

### JSON

```json
[
  { "id": "1", "category": "情報セキュリティ", "question": "…", "answer": "一方向性", "explanation": "…", "source": "R6秋 問1 設問1" }
]
```

| 項目 | CSV 見出し | JSON キー | 必須 |
| --- | --- | --- | --- |
| 分野 | 分野 / カテゴリ | category | |
| 問題 | 問題 / 問題文 | question | ✓ |
| 答え | 答え / 正解 / 解答 | answer | ✓ |
| 解説 | 解説 | explanation | |
| 出典 | 出典 | source | |

`id` は無視します（ファイルごとに番号が振り直されても問題ありません）。重複判定は問題文で行います。

## 公開方法（GitHub Pages）

1. リポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存
3. 数分後に `https://kinchan1830.github.io/OUYO-QUIZ/` で開けます
4. スマホで開き、共有メニューから「ホーム画面に追加」

## 開発

ビルド不要の素の HTML / CSS / JavaScript です。

```sh
python3 -m http.server 8000   # http://localhost:8000 で確認
node --test                   # 取り込み・重複排除・履歴のテスト
```

| ファイル | 役割 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | 画面と操作 |
| `parser.js` | CSV / JSON の読み込み、重複判定キーの作成 |
| `store.js` | 問題と回答履歴の保存 |
| `sw.js` / `manifest.webmanifest` | オフライン対応・ホーム画面追加 |
